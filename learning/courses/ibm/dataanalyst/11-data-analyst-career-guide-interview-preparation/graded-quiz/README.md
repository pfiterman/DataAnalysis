# Graded Quiz - Questions and Answers

## Module 1 - Data Analytics and Generative AI

1. **You are applying for a healthcare data analyst role. The posting emphasizes SQL, Python, and presenting findings from medical device data to non-technical clinicians. You already have SQL skills and some experience with public health datasets. Which step would most strengthen your application first?**
   - [ ] Remove health-related examples so your portfolio appears more general across industries
   - [ ] Learn a new programming language that is not mentioned in the posting so your skills look broader
   - [ ] Add more certifications but leave your projects unchanged
   - [x] Build or refine a portfolio project using health-related data that shows analysis and clear communication of findings

   **Answer:** This directly demonstrates relevant technical skills, domain alignment, and the ability to communicate results to the intended audience.

2. **You have limited time to improve your portfolio before applying for jobs. Which actions would most strengthen it for employers? Select all that apply.**
   - [ ] Add unrelated personal photos and social links to make the portfolio feel more memorable
   - [x] Add a project using a public dataset that includes exploratory analysis and a clear visualization of findings
   - [ ] Replace project descriptions with certificate screenshots so the portfolio looks more formal
   - [x] Organize your GitHub projects by skill area and add README files that explain the work
   - [x] Include a freelance, internship, or volunteer project and explain the problem, your role, and the outcome

   **Answer:** Showing real data work, exploration, and clear communication of results demonstrates practical skill. Clear organization and documentation make it easier for employers to evaluate your projects. Real projects become more valuable when employers can understand what you did and why it mattered.

3. **Two candidates list SQL, Excel, and Tableau on their resumes. One lists only the tool names in a skills section. The other includes a portfolio link and a bullet that says, "Built Tableau dashboards to analyze quarterly sales, reducing reporting time by 30%." Why is the second candidate more compelling?**
   - [ ] The second candidate uses fewer tool names, which makes the resume easier to scan
   - [ ] The second candidate avoids broad claims and keeps the focus on one tool
   - [x] The second candidate connects skills to a specific project and a measurable business outcome
   - [ ] The second candidate no longer needs a separate skills section because the bullet replaces it

   **Answer:** Showing how tools were used in context makes the candidate's experience more concrete and credible.

4. **A hiring manager opens your GitHub profile to judge whether your portfolio is worth a closer look. Which setup is most likely to support a positive first impression?**
   - [ ] One public repository containing mixed files with no structure, so everything is in one place
   - [ ] Several private repositories with strong projects, because privacy makes the work look more professional
   - [x] Several public repositories organized by skill or project type, with updated work and README files explaining each project
   - [ ] A single repository that contains only final screenshots of dashboards, without code or explanation

   **Answer:** Organized, accessible projects with explanations help employers quickly understand what you can do.

5. **You are tailoring your resume for a company that uses applicant tracking systems. Which changes are most likely to improve both discoverability and readability? Select all that apply.**
   - [ ] Use multiple columns and large images to make the page stand out during automated screening
   - [x] Use important job-specific terms in normal, readable bullet points rather than isolating them in a list
   - [x] Maintain a Microsoft Word version of the resume for applications that prefer that format
   - [ ] Put your core skills inside icons and graphics so the resume looks more distinctive
   - [x] Keep the layout simple, with clear headings and minimal decorative elements

   **Answer:** Keywords are most effective when they appear naturally in relevant context. Many systems handle Word files more reliably than heavily designed alternatives. Straightforward formatting makes it easier for automated systems to read the content accurately.

6. **You are early in your career and have one internship, several course projects, and a long-running hobby project building sports dashboards for a local club. What is the best way to use that hobby on your resume?**
   - [x] Include it as a project or relevant interest and highlight the data tools and analysis involved
   - [ ] Omit it because hobbies should never appear on a professional resume
   - [ ] Replace your internship details with the hobby so the resume feels more distinctive
   - [ ] Add it in a personal interests section without explaining the technical work involved

   **Answer:** This approach shows that the hobby provides practical evidence of relevant skills when experience is still growing.

7. **A recruiter spends about 15 seconds scanning your resume before deciding whether to continue. Which combination is most likely to help you pass that first screen?**
   - [ ] A visually striking design and a long summary paragraph at the top
   - [ ] A detailed section about hobbies, clubs, and personal interests before work experience
   - [x] A clear skills section, relevant experience, and evidence that your portfolio supports the role requirements
   - [ ] A full list of every software tool you have ever tried, regardless of relevance

   **Answer:** Recruiters first want to see whether your skills, experience, and examples align with the position.

8. **You are selecting references for a data analyst interview. Which choices would best support your application? Select all that apply.**
   - [ ] Add former coworkers without checking whether their contact information is current
   - [x] Include a professor who knows your project work well and has agreed to be contacted
   - [x] Ask a former manager who supervised your analytics work and confirm what they are allowed to discuss
   - [x] Keep a separate list of reference names, roles, organizations, and contact details ready to provide when asked
   - [ ] Use a relative who knows your personality well but has not seen your work in a professional or academic setting

   **Answer:** A professor can be a strong reference when they can speak specifically about your skills and work. A supervisor who knows your work can provide relevant support, especially if expectations are clarified in advance. Organized reference information helps you respond quickly and professionally during the hiring process.

9. **Which resume bullet best follows the recommended pattern of action, task, and measurable result?**
   - [ ] Worked on reports, dashboards, and analytics tasks as needed
   - [ ] Interested in learning more about dashboards and reporting tools
   - [x] Built interactive Tableau dashboards for marketing, reducing manual reporting time by 40%
   - [ ] Responsible for building dashboards and analyzing data for the team

   **Answer:** This version starts with an action, identifies the work, and shows a measurable result.

10. **You are tailoring your application for two roles: one in e-commerce marketing analytics and one in hospital operations analytics. You already have projects in both areas. What is the best strategy?**
    - [ ] Remove the domain-specific projects so your profile appears broader and more flexible
    - [x] Emphasize the projects, metrics, and examples that match each role's domain and likely business questions
    - [ ] Use the same resume and portfolio emphasis for both roles so your application stays consistent
    - [ ] Focus mainly on education and reduce project detail to avoid overwhelming the reader

    **Answer:** Highlighting the most relevant work for each role shows that you can apply your skills in the right context.

## Module 2 - Applying and Preparing to Interview

1. **A company website is a good place to research a company you're interested in. Why should you pay attention to the language used in the website text?** — 1/
   - [ ] Industry jargon and terminology can indicate that the company is up to date.
   - [ ] The formality of the language can give you an idea of the company culture.
   - [ ] Mistakes can indicate that the company is not legitimate.
   - [x] Repeated keywords can give you an idea of what is important to the company.

   **Answer:** Words that a company frequently uses in their content indicate ideas that are important to them, and you can even use some of the same words in your interview to show you are tuned in to the company's viewpoint.

2. **Why should you check social media to find out about a company you want to join?**
   - [x] You can understand the company's image and corporate culture from what they post.
   - [ ] You can give companies a view of your own life so they can know you better.
   - [ ] You can ask questions about the company to a broad audience.
   - [ ] You can see if former employees have shared feedback.

   **Answer:** Social media posts from the company's account and employee accounts can give you information about current issues at the company and the company culture.

3. **Which three of the following are effective networking methods?**
   - [ ] Talk to people you meet at bars and clubs.
   - [x] Talk to friends about your job search.
   - [x] Take classes to brush up on your professional skills.
   - [x] Join professional groups and attend events.

   **Answer:** Your immediate social circle is a great place to start networking, even if they aren't in your field. Classes can help you meet others in your field, either as classmates or teachers. Professional groups and events are a good way to meet others in your field who might know of job opportunities.

4. **What percentage of recruiters use LinkedIn as part of their candidate search?**
   - [ ] Nearly 50%
   - [ ] Just over 30%
   - [ ] About 75%
   - [x] Almost 90%

   **Answer:** About 87 percent of recruiters use LinkedIn as part of their candidate search.

5. **Which of the following is true about working as a contractor and full-time employee (FTE)?**
   - [ ] Both can expect to work indefinitely.
   - [ ] Both contractors and FTEs usually work full-time hours.
   - [ ] Both contractors and FTEs receive benefits from the company where they work.
   - [x] Contractors and FTEs are generally covered by the same employment laws.

   **Answer:** Most companies don't provide benefits to contractors, although they may receive them from their agencies.

6. **What is a "red flag" that might indicate thinking twice about responding to a job listing?**
   - [ ] A statement about fair hiring practices
   - [ ] Very specific job title
   - [ ] No industry jargon or highly technical terms
   - [x] Broad expectations about the position with few specifics

   **Answer:** A good job listing should define the position clearly, with tasks that make sense for the role and the job level.

7. **Which two statements are true about qualifications in job listings?**
   - [x] You don't need to have all of the qualifications listed.
   - [ ] The qualifications will outline what the person in the role is expected to do.
   - [ ] The qualifications often will not include how many years of experience are expected.
   - [x] The qualifications may include both hard and soft skills.

   **Answer:** You should have all the required qualifications and many of the preferred ones, but you don't need them all. Job qualifications may include hard skills like programming languages, but also soft skills like communication and working with a team.

8. **What is true about rehearsing for interviews?**
   - [ ] You won't need an elevator pitch.
   - [ ] It's not helpful to watch yourself in a mirror.
   - [x] It's important to practice articulating what you want to say.
   - [ ] You can't predict the questions, so there's no point in finding examples.

   **Answer:** Even if you know your information very well, it can be difficult to speak it out loud, and practice will make that easier.

9. **What is a mock interview?**
   - [x] A practice interview that enables you to rehearse your answers at home
   - [ ] An interview where you are given extremely difficult questions
   - [ ] An interview where you only need to answer the questions you have prepared
   - [ ] A practice interview given by the company you want to join that doesn't actually count

   **Answer:** You can enlist a friend to role-play an interviewer so that you can practice your elevator pitch and some answers to common questions.

10. **What is a good way to prepare for first interviews?**
    - [ ] Prepare a written document of your answers that you can hand out at your interviews.
    - [ ] Memorize everything you have researched.
    - [ ] Decide on the salary and benefit package you will accept.
    - [x] Use your notes to compose questions you want to ask the company.

    **Answer:** Interviewers will give you a space to ask your own questions, so you need to be prepared for this part of the interview as well.

## Module 3 - Interviewing

1. **What is true about the overall interview process?**
   - [ ] Interviews are all different, and it's not really possible to prepare effectively.
   - [ ] Candidates generally don't ask questions of the interviewers.
   - [x] Interview processes can vary depending on factors like the type of position and size of company.
   - [ ] Second-round screens are usually the same.

   **Answer:** Interviews at a large company can be very different from those at a small company, and entry-level interviews are often different from those for higher-level roles.

2. **Why would you be asked to sign a non-disclosure agreement (NDA) before a code challenge?**
   - [x] The company does not want you to share the problem with other potential candidates.
   - [ ] They want to save time on a possible hiring process.
   - [ ] They may want to use your work in a later project.
   - [ ] They don't want anyone to know what projects the company may be working on.

   **Answer:** Companies create or source a code challenge to fit the position they're hiring for, and they don't want the problem to be shared out.

3. **What is true about coding challenges?**
   - [x] In them, you work on your own time at home and then submit your work for review.
   - [ ] A coding challenge is usually the first step in an interview process.
   - [ ] You will not need to create visualizations.
   - [ ] You will need to figure out how to do the problem yourself – no instructions are provided.

   **Answer:** The company will usually send you information and links that you need, as well as a way to submit your work back to them.

4. **What are some good things to review after first-round interviews to prepare for second-round screens?**
   - [ ] Whether you are still interested in the position
   - [x] Whether there was a question that you weren't prepared for
   - [x] The names and positions of any interviewers you have met
   - [x] What went well and what caught the interest of your interviewers

   **Answer:** Now is a good time to review and prepare a good answer for any questions you didn't expect. You may meet these interviewers again, or they may come up in conversation. You'll want to be knowledgeable about the points that went well and prepare follow-up questions.

5. **What might you expect in a human resources (HR) screen?**
   - [ ] Behavioral questions about your working style
   - [x] A brief orientation about the company and its products or services
   - [ ] Questions to test technical skills
   - [ ] Information about other candidates for the position

   **Answer:** The HR representative is likely to make sure you understand the basics about the company.

6. **What is a good way to prepare before a final interview?**
   - [ ] Stay fresh in your responses by not reading over your notes.
   - [ ] Leave appearance choices until the morning of the interview – there are better things to think about.
   - [x] Test your equipment if the interview is virtual.
   - [ ] Skip breakfast to save time.

   **Answer:** Ensure that you can successfully connect to the virtual interview and that your equipment is working properly beforehand, so you can concentrate on the interview.

7. **What is true about asking interviewers questions during an interview?**
   - [ ] It's helpful to be candid with your concerns about issues like work load and holidays.
   - [ ] It's best to think of questions spontaneously during the interview.
   - [ ] It's a good time to negotiate compensation.
   - [x] It's a chance to show how serious you are about the job and how well you prepared.

   **Answer:** Good questions show that you did your homework and are thinking about how you will step into the role if given a chance.

8. **In the United States, what is illegal to ask in a job interview?**
   - [x] Marital status
   - [x] Gender and sexual orientation
   - [x] Race or nationality
   - [ ] Legal or arrest record

   **Answer:** It is illegal to discriminate on these bases in the United States, so it's illegal to ask these questions.

9. **What is "culture fit"?**
   - [ ] Whether a candidate fits the company's equal-opportunity policies
   - [x] How well a candidate fits in with the company's existing culture
   - [ ] Whether a candidate can follow the company's dress code
   - [ ] Another name for immigration status

   **Answer:** Beware of questions about this – it can often be a mask for unconscious (or intentional) bias.

10. **What should you do if you are offered a new position?**
    - [ ] Stop contacting companies you previously interviewed with.
    - [ ] Start the new job immediately.
    - [x] Consider factors that might call for a compensation negotiation.
    - [ ] Accept immediately.

    **Answer:** Correct.
