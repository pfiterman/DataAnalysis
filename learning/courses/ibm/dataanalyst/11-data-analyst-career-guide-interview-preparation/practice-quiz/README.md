# Practice Quiz - Questions and Answers

## Module 1 - Understanding the Role and Opportunities of Data Analysts

1. **Which statement best describes the primary role of a data analyst?**
   - [ ] Designing and maintaining the systems that store organizational data
   - [ ] Writing software applications for customers to use in daily operations
   - [ ] Building predictive machine learning systems as their main responsibility
   - [x] Gathering, analyzing, and communicating data insights to support business decisions

   **Answer:** A data analyst turns data into insights and communicates those insights in a way that supports decision-making.

2. **Which of the following are common tasks performed by data analysts? Select all that apply.**
   - [x] Visualizing data to communicate findings to stakeholders
   - [x] Identifying patterns and correlations to answer business questions
   - [ ] Managing data repositories so other data professionals can access them
   - [x] Inspecting and cleaning data before analysis
   - [ ] Training machine learning models as a routine primary duty

   **Answer:** Presenting findings through visualizations is part of how analysts share insights with others. Analysts look for trends, relationships, and patterns that can support action. Data analysts also preprocess data so it is suitable for analysis.

3. **Which set of skills most accurately reflects key technical skills for data analysts?**
   - [ ] Contract negotiation, hiring, and procurement management
   - [ ] Copywriting, illustration, and video production
   - [x] SQL, Python or R, spreadsheets, and data visualization tools
   - [ ] Network setup, device repair, and system troubleshooting

   **Answer:** Query languages, programming languages, spreadsheet tools, and visualization tools are key technical skills for data analysts.

4. **In which situation is domain knowledge likely to make a data analyst more effective?**
   - [ ] Replacing damaged equipment on a factory floor
   - [ ] Choosing paint colors for a company office renovation
   - [ ] Setting up employee Wi-Fi access across departments
   - [x] Interpreting medical data when looking for health-related patterns

   **Answer:** Knowledge of the medical field can help an analyst interpret results more effectively and understand the context of the data.

5. **Which statement best describes how data analyst opportunities vary across organizations?**
   - [ ] Data analysts are mainly hired by large technology companies and rarely elsewhere
   - [ ] Data analysts usually perform the same tasks regardless of the organization
   - [ ] Data analysts are generally limited to startup roles with irregular hours
   - [x] Data analysts can work in many industries, and their work may differ by company size and context

   **Answer:** Opportunities are broad, and working style and responsibilities can vary across organizations.

## Module 1 - Portfolios and Resumes

1. **Why is a portfolio especially valuable for data analyst job seekers?**
   - [ ] It serves mainly as a personal website to summarize your education and contact information
   - [ ] It mainly provides a place to display certificates without showing project work
   - [ ] It replaces the need for a resume by serving as the only application document
   - [x] It gives employers a way to examine projects that demonstrate your skills

   **Answer:** A strong portfolio lets employers review examples of your work and the skills those projects show.

2. **Which of the following are good examples of work to include in a data analyst portfolio? Select all that apply.**
   - [ ] Personal photos and unrelated social media content
   - [ ] A list of completed certificates with no project examples or explanation
   - [x] Course or capstone projects built from meaningful datasets
   - [x] Freelance or internship projects that demonstrate practical problem solving
   - [x] Documented participation in data challenges such as Kaggle competitions

   **Answer:** Course and capstone work can be strong portfolio content when it shows relevant skills. Freelance and internship work can be valuable portfolio material when it shows how you solved real problems. Competitions can provide practical examples of applied data analysis work for a portfolio.

3. **Which action best reflects a recommended approach to building a new portfolio project?**
   - [x] Using a real-world public dataset to perform exploratory analysis and create visualizations
   - [ ] Choosing only polished sample data so the project avoids any data cleaning
   - [ ] Avoiding public datasets because employers only value original proprietary data
   - [ ] Describing a business problem without building or documenting any analysis

   **Answer:** Using real-world public data for exploration and visualization is a recommended way to build a project.

4. **Which GitHub practice is recommended for strengthening a data analyst portfolio?**
   - [ ] Uploading projects once and leaving them unchanged over time
   - [ ] Keeping all of your work in a single repository without project descriptions
   - [x] Hosting several projects, updating them often, and adding a README file
   - [ ] Using GitHub only to store code privately instead of sharing visible examples of your work

   **Answer:** Multiple projects, frequent updates, and clear README files help present your work effectively.

5. **Which practices help make a resume easier for applicant tracking systems and search tools to read? Select all that apply.**
   - [x] Keeping a Microsoft Word version of the resume available
   - [ ] Using multiple columns, images, and creative layouts to stand out visually
   - [x] Using a simple layout that avoids elements ATS software may misread
   - [ ] Hiding important skills inside graphics and decorative design elements
   - [x] Using relevant keywords from job postings in normal, readable text

   **Answer:** Many ATS tools work best with Microsoft Word resumes. Simple formatting makes it easier for ATS software to scan the resume accurately. Using keywords purposefully in regular text helps systems recognize relevant qualifications.

6. **In which situation is it most appropriate to include hobbies or interests on a resume?**
   - [ ] Never, because hobbies and interests should always be excluded from resumes
   - [x] When your experience is limited and the hobbies relate to the role you want
   - [ ] Whenever you have hobbies, whether or not they relate to the job
   - [ ] When you want to make the resume look fuller even though your experience is already strong

   **Answer:** Relevant hobbies can help strengthen a resume when professional experience is limited.

## Module 2 - Applying and Preparing to Interview

1. **What is an informational interview?**
   - [ ] An interview held between interviewers to familiarize themselves with a candidate
   - [x] An interview someone holds with a professional to learn more about a field of work
   - [ ] An article published by a news source about a company
   - [ ] An interview a company holds with a candidate to just get better acquainted

   **Answer:** Informational interviews can be a valuable part of industry research.

2. **What is the top networking website?**
   - [ ] GitHub
   - [ ] Reddit
   - [ ] Monster
   - [x] LinkedIn

   **Answer:** LinkedIn is used by 87% of recruiters and hundreds of thousands of professionals around the world.

3. **Which of the following is a "red flag" in a job listing, indicating that you should consider very carefully before applying?**
   - [ ] Lack of industry-specific jargon
   - [ ] No recruiter name listed
   - [ ] No salary listed
   - [x] Unrealistic requirements

   **Answer:** Companies that demand difficult requirements, such as several years' experience for an entry-level role, may not understand the role or may be exploitative.

4. **What are the three basic components of a good elevator pitch?**
   - [x] Introduce yourself, tell what you have done recently, and list your professional goals
   - [ ] Say your job title, your latest personal project, and your contact information
   - [ ] State the job you're looking for, the company you want to target, and your preferred salary
   - [ ] Introduce yourself, ask what the person you're talking to does, and ask if they know of any open jobs

   **Answer:** Correct. This is a quick thumbnail sketch of your job search that will serve you in many different situations if you have it ready to say.

5. **When you are reading a company's website because you plan to interview with them, why should you pay attention to keywords you spot on the site?**
   - [ ] It can help you find the company more easily when you do a web search for articles.
   - [x] It can help you understand the image the company wants to project and maintain.
   - [ ] It can be helpful for tracking purposes.
   - [ ] You might find inconsistencies or mistakes that you could alert the company to.

   **Answer:** Language choices can tell you a lot about a company and help you communicate with them effectively.

## Module 3 - Interviewing

1. **What are three common types of second-round interviews?**
   - [ ] Mock interview _(selected — incorrect)_
   - [x] Technical interview
   - [x] Human resources screen
   - [x] Team interview

   **Answer:** Correct. It’s common for a candidate to speak with an HR representative in the second round. Often a team lead will discuss behavioral questions with a candidate. A technical lead often interviews a candidate to assess technical skills.

2. **Coding challenges vary in scope and complexity depending on `_________________`.**
   - [ ] Whether the data is downloaded
   - [x] Seniority and job description
   - [ ] City or region of the company
   - [ ] Round of interviews

   **Answer:** Entry-level jobs may ask for an easier challenge, while senior positions will assign a more difficult or complicated problem.

3. **Why might a company ask you to sign a non-disclosure agreement (NDA) before working on a coding challenge?**
   - [ ] To protect downloaded data sets from being distributed
   - [ ] To protect the company in case they don't own the rights to the information used in the challenge
   - [ ] To lay the legal groundwork in case you are not hired and to protect themselves from libel
   - [x] To keep you from sharing the problems with other applicants and to establish who owns the work you do on the challenge

   **Answer:** NDAs keep things clear and legal, protecting the company and the applicant.

4. **Which of the following is an appropriate question to ask at a final interview?**
   - [x] What's the next step in the hiring process?
   - [ ] How much time off is included in this role?
   - [ ] Can you offer me a higher salary?
   - [ ] What does this company do?

   **Answer:** It's appropriate to ask about the general sequence and timing of the interview process in that company.

5. **In the STAR method for answering interview questions, STAR stands for:**
   - [x] Situation, Task, Action, Result
   - [ ] Saw, Took Action, Aimed, Reviewed
   - [ ] Start, Test, Add, Result
   - [ ] Self, Team, Action, Review

   **Answer:** This is an effective format for answering behavioral and situational interview questions.
